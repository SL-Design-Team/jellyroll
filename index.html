Build with JellyRoll

Describe the screen you want and an AI agent will build it using the real JellyRoll components and tokens. No coding required — these steps are the same for everyone.

  1. 1
    Install the JellyRoll command

    Install once in your terminal. This adds /jellyroll to any Claude Code session.

    Terminal
    BASE=https://raw.githubusercontent.com/SL-Design-Team/jellyroll/main/.claude/commands
mkdir -p ~/.claude/commands
curl -sL $BASE/jellyroll.md -o ~/.claude/commands/jellyroll.md
curl -sL $BASE/jellyroll-setup.md -o ~/.claude/commands/jellyroll-setup.md

    Restart Claude Code, then type /jell to make sure it worked.

  2. 2
    Describe what you want to build

    Start a new Claude Code session and tell the agent what you need. Plain English is fine.

    Claude Code
    /jellyroll build a connection list page with a KPI row and a status table

    Describe it like you would to a designer:

    • what the screen is for
    • what the user is doing
    • any key requirements

    Name the product area if you know it (Designer, Monitor, AutoSync, etc.).

  3. 3
    Open it, then ask for changes

    The agent will create a working prototype and give you a .html file. Open it in your browser — nothing to install.

    Claude Code
    • “Make the table denser.”
    • “Add an empty state.”
    • “Try a mobile layout.”

    Keep refining in the same conversation.

  4. 4
    Publish it when you're ready

    Ask the agent to publish the prototype and share the link. It will create a repo in SL-Design-Team and turn on GitHub Pages for you.

    Your prototype is live
    https://sl-design-team.github.io/…

    Share the link with your team for feedback. Internal repos are visible to SnapLogic accounts only.

Works with any AI agent, or coding by hand

Use /jellyroll in Claude Code, other AI agents, or in your own code. You'll always get the latest JellyRoll components, tokens, and guidance.
