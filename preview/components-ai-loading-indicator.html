mark
The SnapGPT mark (assets/snapgpt-icon.svg) in --ai-accent, at 35% opacity. Each of its six nodes has a 1.4px ring. Never redraw the mark; animate the rings only.
motion
Each ring goes 0 → 1 → 0 opacity on a 1.8s cycle, ease-in-out, 300ms after the one before it, clockwise from the top node.
label
13/20 Medium, Indigo-900 (15:1 on --ai-tint). A band of --ai-accent crosses the text every 1.4s. Name the task: "Generating column descriptions". Name SnapGPT only on SnapGPT surfaces: "SnapGPT is writing a draft". Use "Thinking…" only where the task has no name.
time
Elapsed time in mono 12/18, Grey-800, tabular numbers: 4.2s, then 1m 05s. Starts when the task starts.
Stop
Tertiary sm button. Stop keeps what the AI already made. The focus stays on the control that started the task.
end
The loader and the result note are one slot. The mark stops. The row cross-fades into the note (--duration-normal, 200ms, --ease-standard). The slot takes the height of the note. One change at a time.
a11y
The label is role="status", so it is the announcement and Stop is not read. The time is aria-hidden, so screen readers do not read every tick. A failure is role="alert" and stays until the user acts.
reduced motion
The mark is static at full opacity, the shimmer stops, the time still counts. The end changes with no animation.
vs spinner
Use this indicator wherever AI works on a task: SnapGPT, a table that the AI fills, a form, an editor. The task can take from a few seconds to a minute. Use the Spinner for other waits under 10 seconds.
