WCAG criteria that writing affects

WCAG 2.1 AA is our baseline, and the Accessibility page covers the design and engineering side. These are the criteria a writer controls.

CriterionLevelWhat it asks of writers
1.1.1 Non-text contentAGive every meaningful image, icon, and chart a text alternative. Hide decorative ones.
1.3.1 Info and relationshipsAWrite headings, lists, and labels as real structure, not only formatting.
1.3.3 Sensory characteristicsADon’t rely only on shape, color, size, position, or sound in instructions.

2.4.2 Page titledAGive each page a title that describes its topic.

Write plainly

Keep it short and simple 3.1.5
Aim for one verb per sentence and short paragraphs. Read the text aloud, imagining a screen reader speaking it.
Lead with what matters
Put the key information first so readers know where to focus.
Spell out and, plus, and about
Screen readers can misread or skip &, +, and ~. Use symbols only where they’re part of a name.
Explain abbreviations and unusual terms on first use 3.1.33.1.4
Write single sign-on (SSO) the first time, then SSO.
Don’t use all caps for emphasis
Some screen readers spell all-caps words letter by letter.
Don’t force line breaks inside a sentence
They break in resized windows and at larger text sizes.
Keep the vocabulary consistent 3.2.4
One name for one thing. The Terminology page is the reference.

Instructions and labels

Don’t depend on position, shape, or color alone 1.3.3
Write Select Save, not Select the green button on the right. Words such as left, above, and below don’t help someone using a screen reader.
Use verbs that work with any input
Select, choose, and enter work with a mouse, a keyboard, touch, and voice. Use click only for a pointer-only action.
Label every input with visible text 3.3.2
State required and optional in words, and give the format or limits before the person types.
Start a control’s accessible name with its visible label 2.5.3
If the button says Add Snap, the name starts with Add Snap, so voice control users can say what they see.
Don’t rely on a toast for anything people must read or act on
Toasts disappear. Anything essential belongs in a banner, modal, or the page itself.

Links

Make link text meaningful on its own 2.4.4
Read the Snaplex setup guide, not Click here. Links should make sense out of context, as in a list of links.
Keep Learn more specific
Learn more is fine after a sentence that names the topic. When several links on a page share that text, give each its own accessible name: Learn more about Snaplexes.
Say when a link opens something unexpected
A new tab, a download, or a file type. Open the report (PDF, opens in a new tab).
Don’t use a raw URL as link text
Describe the destination instead.
Make links look like links 1.4.1
Use more than color, such as an underline.

Images, icons, and charts

Describe the purpose, not the appearance 1.1.1
Keep alt text to a sentence or two. Don’t start with Image of or Photo of.
Hide decorative images
Use empty alt text (alt="") so they’re skipped.
Name icon-only controls by their action
Delete, not the name of the icon.
Give a chart a text takeaway and the data 1.1.1
State the point in a sentence, and make the underlying numbers available in a table.
Use real text, not an image of text 1.4.5

Headings, lists, and tables

Use real heading levels to show hierarchy 1.3.1
Don’t skip levels, and don’t fake a heading with bold text.
Describe what a heading covers 2.4.6
Write headings and labels that tell people what’s under them.
Use a real list for a list
Use parallel items, and introduce the list with a sentence that ends in a colon.
Introduce a table in a sentence before it
Use short, specific column headings.

Before you ship

  1. Read it aloud. If it trips you up, it will trip up a screen reader.
  2. Read every link on its own. Does each one say where it goes?
  3. Check every instruction. Would it still work without seeing color, shape, or position?
  4. Check every error and status message. Does it make sense without its field or heading?
  5. Check every image and icon. Does each have a useful name, or is it deliberately hidden?
  6. Run a readability check, and aim for roughly an eighth-grade level.
  7. Test with a screen reader.
