icons
Leading magnifier 16px, subtle grey. Replaced with spinner during async debounced search (350ms). Trailing X appears only when input has content.
debounce
Default 350ms (--validate-debounce) before firing the search request. Adjust per use case — instant for local lists, longer for remote APIs.
type
Use type="search" — provides native clear button on some platforms (which is hidden by the system's CSS reset; the explicit clear button replaces it).
shortcut
Global search fields show ⌘K / Ctrl+K badge inline. Pressing the shortcut opens the Search overlay component. The badge is passive text, so it may share the trailing slot with the clear ×.
trailing slot
The clear × owns it. Nothing else interactive goes in there — see Field anatomy's clear + trailing. A group by, sort, density, or saved view control acts on the results, not on the text in the field, so it sits outside as a sibling button in the same toolbar row (the composition in Filter, sort, faceted search), where it can show a label and its current setting rather than hiding behind an icon. Only passive things may share the slot with clear: the ⌘K badge, a validation check, a loading spinner.
surfaces
Default is the bordered white field. Add sl-search--inverse on dark surfaces (Designer rail, SnapGPT panel, Indigo 1000 nav) for a near-transparent fill with a Blue-300 25% border — the same track border the inverse Segmented control uses. Inverse is a surface modifier only: compose it with sl-search--sm for the compact rail size. The teal focus ring is identical on every surface. There is no filled variant.
a11y
Wrap in <form role="search"> if the field is the primary search affordance on the page. Clear button: aria-label="Clear search".
